# Jesús es el camino

Aplicación web construida con **Vue 3**, **Vite** y **Tailwind CSS** centrada en Juan 14:6 (RVR1960), con una experiencia visual cuidada, una explicación del versículo y una sección de meditación diaria interactiva.

## Características

- Hero principal con enfoque visual sobre **Juan 14:6**.
- Explicación del significado de *camino, verdad y vida*.
- Tarjetas interactivas de **meditación diaria** con efecto de giro.
- Interfaz responsive.
- Estilo moderno con soporte visual tipo claro/oscuro en el componente de meditación.

## Stack

- **Vue 3**
- **Vite**
- **Tailwind CSS**
- **lucide-vue-next**

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build de producción

```bash
npm run build
```

## Vista previa local

```bash
npm run preview
```

## Contenido

El proyecto usa texto bíblico de la **Reina-Valera 1960** y presenta una experiencia enfocada en reflexión cristiana, lectura y meditación.

## Despliegue

Este proyecto es compatible con plataformas de despliegue estático como **Vercel**.
